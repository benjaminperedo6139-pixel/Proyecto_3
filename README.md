# Proyecto 2 - Algoritmo de Dijkstra

Este proyecto implementa el algoritmo de Dijkstra en Python para encontrar la ruta más corta entre dos nodos de un grafo.

## Funcionalidades

- Agregar conexiones entre nodos.
- Asignar pesos a las conexiones.
- Encontrar la ruta más corta.
- Calcular el costo total del recorrido.
- Guardar y cargar conexiones mediante un archivo CSV.
- Interfaz gráfica utilizando Streamlit.

## Tecnologías utilizadas

- Python
- Streamlit
- NetworkX
- Matplotlib
- CSV

## Ejecución

Instalar las dependencias necesarias y ejecutar:

```bash
streamlit run app.py
